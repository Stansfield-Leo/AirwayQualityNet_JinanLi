# AirwayQualityNet: Branch-level Airway Structural Quality Assessment Based on AirMorph Features

## Overview

AirwayQualityNet is a branch-level airway structural quality assessment framework developed based on AirMorph-generated airway representations.

The original AirMorph pipeline extracts anatomical and structural information from CT-derived airway trees, including branch-level geometric characteristics, spatial information and topology-related features. This repository investigates whether these extracted branch-level features contain sufficient information for automatically identifying potentially abnormal airway branches.

The current implementation focuses on a lightweight Multi-Layer Perceptron (MLP) classifier as a baseline model. The objective is to evaluate the feasibility of downstream airway quality assessment using AirMorph feature representations, rather than replacing the original airway segmentation or anatomical classification pipeline.

The current framework contains three main stages:

1. Extract branch-level feature representations from AirMorph outputs.
2. Generate synthetic airway corruption samples for supervised learning.
3. Train an MLP classifier to identify potentially corrupted airway branches.


## Method Overview

The overall workflow is:

The model takes 20-dimensional AirMorph branch-level features as input and predicts the probability of a branch being structurally abnormal.

# Dataset Construction


## build_dataset.py

`build_dataset.py` converts AirMorph-generated branch feature files into a structured machine learning dataset.

The script reads:

`{case_id}_airway_feature_cls.npy`

generated by the AirMorph pipeline.

Each file contains branch-level feature vectors extracted from the airway tree. The script processes multiple airway cases and converts the original numpy representation into a CSV-based dataset.

The output file is:

`branch_features.csv`

Each sample represents one airway branch and contains:

- `case_id`
- `branch_id`
- `feature_0` to `feature_19`

These 20 features are used as the input representation for airway branch quality assessment.


## branch_features.csv

`branch_features.csv` stores the extracted AirMorph branch-level feature representation.

Each row corresponds to one airway branch.

The dataset contains:

- airway case information
- branch identity
- 20 numerical AirMorph features

These features describe branch-level structural and anatomical properties extracted from the airway tree.


# Synthetic Airway Corruption Generation


## corruption_generator.py

`corruption_generator.py` generates graph-level airway corruption samples.

The purpose of this experiment is to investigate whether AirMorph features can identify branches affected by airway topology damage.

The script simulates airway graph corruption by modifying airway connectivity and identifying affected branches.

The generated labels are stored in:

`branch_labels.csv`

Label definition:

- `0`: corrupted airway branch
- `1`: normal airway branch


This experiment provides a graph corruption baseline.


## feature_corruption_generator.py

`feature_corruption_generator.py` generates synthetic feature-level airway abnormalities.

Instead of modifying airway graph connectivity directly, this method modifies AirMorph feature values to simulate abnormal airway structures.

Current corruption strategies include:

- branch length modification
- branch volume modification
- branching relationship modification
- spatial feature perturbation

The generated dataset is:

`training_dataset_feature_corruption.csv`

This dataset is used for training the AirwayQualityNet baseline model.


# Dataset Processing


## merge_dataset.py

`merge_dataset.py` combines branch-level features and corruption labels.

Input:

- `branch_features.csv`
- `branch_labels.csv`

The datasets are matched using:

- `case_id`
- `branch_id`

The output is:

`training_dataset.csv`

This file contains both AirMorph features and corresponding branch-level labels.


## dataset_summary.py

`dataset_summary.py` performs dataset quality inspection before model training.

The script checks:

- total number of samples
- number of airway cases
- branch distribution
- missing values
- feature statistics
- zero variance features

This step ensures that the generated dataset is suitable for machine learning experiments.


# AirwayQualityNet Model


## train_mlp.py

`train_mlp.py` trains the AirwayQualityNet baseline model.

The current model is a lightweight Multi-Layer Perceptron classifier.

Architecture:


Input:
20 AirMorph Features

Linear:
20 → 64

ReLU

Linear:
64 → 32

ReLU

Linear:
32 → 1


The output represents the probability of a branch being structurally abnormal.


## Training Strategy

The training procedure includes:

- case-level train/validation/test split
- feature normalization using StandardScaler
- weighted binary classification loss
- Adam optimizer
- validation loss based checkpoint selection


Case-level splitting is applied to prevent branches from the same airway tree appearing in both training and testing subsets.


The best performing model is saved as:

`best_airway_mlp.pth`


# Experimental Results


The current experiment uses:

- Dataset: ATM22
- Number of cases: 40
- Number of airway branches: 7016
- Input features: 20 AirMorph branch-level features


The AirwayQualityNet baseline achieved:

| Metric | Value |
| --- | --- |
| ROC-AUC | 0.874 |
| F1-score | 0.899 |


These results demonstrate that AirMorph branch-level feature representations contain useful information for detecting synthetic airway structural abnormalities.


# Limitations

The current abnormal samples are generated using synthetic corruption strategies.

Therefore, the current model evaluates the ability to identify simulated airway structural inconsistencies rather than real clinical reconstruction errors.

The current work should be considered as a feasibility study for AirMorph downstream quality assessment.
