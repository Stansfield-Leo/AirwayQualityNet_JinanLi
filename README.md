# AirwayQualityNet-JinanLi: 
Branch-level Airway Structural Quality Assessment Based on AirMorph Features

## Overview

This repository contains the implementation of AirwayQualityNet, a branch-level airway structural quality assessment framework based on AirMorph-generated airway feature representations.

The project investigates whether branch-level anatomical and structural information extracted from AirMorph can be used for downstream airway quality assessment.

Instead of modifying the original AirMorph segmentation and anatomical classification pipeline, this work focuses on analysing AirMorph outputs and developing a lightweight machine learning framework for identifying potentially abnormal airway branches.

The current implementation establishes a baseline framework consisting of:

1. AirMorph branch-level feature extraction.
2. Synthetic airway corruption generation.
3. MLP-based branch abnormality classification.

The objective of this repository is to evaluate whether AirMorph-generated branch features contain sufficient information for airway structural consistency assessment and provide a foundation for future topology-aware airway refinement.


## Main Contributions

The main contributions of this repository include:

- Construction of a machine-learning-ready airway branch feature dataset from AirMorph outputs.

- Development of synthetic airway corruption strategies for branch-level quality assessment.

- Implementation of a lightweight Multi-Layer Perceptron classifier for airway branch abnormality detection.

- Evaluation of AirMorph feature representations for downstream structural quality analysis.

- Establishment of a baseline framework for future airway topology validation and repair.

## Input Description

The current framework uses branch-level feature representations generated by AirMorph.

The input file format is:

airway_feature_cls.npy

Each file contains branch-level feature vectors extracted from airway tree structures.

The extracted representation contains 20 numerical features describing branch-level structural and anatomical characteristics.

The original numpy files are converted into structured CSV datasets for machine learning experiments.

Description:
Feature corruption training dataset.


Each branch sample contains:

- Case identifier.
- Branch identifier.
- Twenty AirMorph branch-level features.
- Binary quality label.


Label definition:

0 : corrupted branch

1 : normal branch


## Synthetic Corruption Generation


### Feature-level Corruption

The feature corruption module generates abnormal airway branch samples by modifying AirMorph feature values.

Current corruption strategies include:

- Branch length perturbation.
- Branch volume perturbation.
- Branching relationship modification.
- Spatial feature perturbation.

The generated dataset is:

training_dataset_feature_corruption.csv

This dataset is used for training the AirwayQualityNet baseline model.


### Graph-level Corruption Baseline

The graph corruption module simulates airway structural damage by modifying airway graph connectivity.

Affected branches are identified and assigned binary labels.

The generated label file is:

branch_labels.csv


## Model Description

The current AirwayQualityNet implementation uses a lightweight Multi-Layer Perceptron classifier.

The model receives 20 AirMorph branch-level features as input.

Model structure:

```text
AirMorph Branch Features
|
|-- 20-Dimensional Feature Vector
|
v
Hidden Layer 1
|
|-- Fully Connected: 20 → 64
|-- ReLU
|
v
Hidden Layer 2
|
|-- Fully Connected: 64 → 32
|-- ReLU
|
v
Output Layer
|
|-- Fully Connected: 32 → 1
|
v
Branch Abnormality Probability
```


The model predicts the probability of a branch being structurally abnormal.

## Usage


Step 1: Build Branch Feature Dataset

Command:

python3 build_dataset.py

This script extracts AirMorph branch-level features and generates:

branch_features.csv


Step 2: Generate Corruption Samples

Feature corruption:

python3 feature_corruption_generator.py

Graph corruption baseline:

python3 corruption_generator.py


Step 3: Dataset Inspection

Command:

python3 dataset_summary.py

The script checks:

- Dataset size.
- Number of airway cases.
- Branch distribution.
- Missing values.
- Feature statistics.


Step 4: Train AirwayQualityNet

Command:

python3 train_mlp.py

The training pipeline includes:

- Case-level train/validation/test splitting.
- Feature normalization.
- Weighted binary classification loss.
- Validation-loss based model selection.

The best model checkpoint is saved as:

best_airway_mlp.pth

## Experimental Results

The current experiment uses:

- Dataset: ATM22.
- Number of cases: 40.
- Number of airway branches: 7016.
- Feature dimension: 20.


The AirwayQualityNet baseline model was evaluated on the synthetic feature corruption detection task.

The obtained results are:

Metric:

ROC-AUC

Value:

0.874


Metric:

F1-score

Value:

0.899


The results demonstrate that AirMorph branch-level feature representations contain useful structural information for distinguishing synthetic abnormal airway branches.

These results indicate the feasibility of using AirMorph-derived features for downstream airway structural quality assessment.


## Limitations

The current framework has several limitations.

First, the abnormal airway samples are generated using synthetic corruption strategies rather than expert-annotated clinical airway reconstruction errors.

Therefore, the current model evaluates the ability to detect simulated structural inconsistencies instead of directly measuring clinical airway abnormality detection performance.

Second, the current implementation focuses on branch-level quality assessment and does not yet perform automatic airway topology correction.

Third, the current experiment is based on a limited number of airway cases. Further evaluation using larger datasets and manually annotated airway quality information is required.


## Future Work

Future development directions include:

- Development of more realistic topology-aware airway corruption strategies.

- Integration of graph-based airway representations for modelling airway connectivity.

- Construction of expert-annotated airway quality evaluation datasets.

- Development of automated airway topology repair based on predicted branch reliability scores.

- Extension from MLP-based classification to Graph Neural Networks and Transformer-based airway representation learning.
